# Bitmeyen Çay Demleme Makinesi

## Resmi Açıklama

Bu proje, Türkiye'nin en büyük sorunlarından biri olan "çayın asla bitmemesi" fenomenini bilimsel ve tamamen ciddi bir şekilde simüle etmektedir. Yıllarca süren araştırmalar sonucu, bir çay demleme işleminin teorik olarak sonsuza kadar devam edebileceği kanıtlanmıştır. Bu kod, o kanıtın canlı örneğidir.

### Özellikler
- Asla bitmez. Gerçekten asla.
- Her 3 saniyede bir çay daha koyu olur.
- Rastgele olaylar: demlik devrilir, şeker biter, misafir gelir, çay soğur ama yine demlenir.
- Ctrl+C ile ancak durur, yoksa sonsuza kadar gider.
- %100 Türkçe, %200 absürt.

### Kurulum
```bash
python3 cay_demle.py
```

### Uyarı
Bu kodu çalıştırmadan önce gerçek çay demleyin. Yoksa kod sizi kıskanabilir.

### Katkıda Bulunma
Lütfen katkıda bulunmayın. Çay zaten yeterince karışık.
